# Конструктор расписания ИЕНИМ — MVP

## Запуск на Windows

Из корня проекта в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
.\.venv\Scripts\python.exe -m parser.importer
.\.venv\Scripts\python.exe mvp_1.py --scope c25,c26,c27,c38,c45
```

Импортёр читает Excel из `parser/tables` и формирует `parser/data.json`. Физкультура из импортированной сетки передаётся решателю как закреплённые события. Для заранее занятой аудитории можно запустить импортёр с `--parse-room-occupancy`.

Решатель формирует `outputs/schedule.xlsx` и `outputs/result.json`. В Excel есть общая сетка на семестр, лист диагностики и лист непоставленных занятий. Частота недель указывается в занятии.

Команда выше ограничивает запуск пятью курсами для демо. Для полного набора удалите из команды `--scope c25,c26,c27,c38,c45`. Автоматически выбирается монолитная модель для малой задачи и двухфазная (сначала слоты, затем аудитории) для крупной. Монолитная оценка ограничена `max_estimated_vars`; в двухфазном режиме отдельно оцениваются размеры каждой фазы. Полный запуск на актуальных данных пока требует нагрузочной проверки.

## Параметры решателя

- `--input PATH` — JSON импортёра; по умолчанию `parser/data.json`.
- `--output PATH` — Excel; по умолчанию `outputs/schedule.xlsx`.
- `--json-output PATH` — JSON результата; по умолчанию `outputs/result.json`.
- `--scope c1,c2` — ограничить запуск указанными ID курсов.
- `--max-time SECONDS` — лимит времени поиска.
- `--strategy auto|monolithic|two_phase` — стратегия решателя.

## Формат и ограничения

Контракт JSON импортёра описан в `docs/SCHEMA-course-instances.md`, ограничения решателя — в `docs/solver-constraints.md`. Для полной проверки нужны актуальные книги импорта, включая закреплённые занятия, и нагрузочный запуск на целевой машине. Текущая модель двухфазная, но время сборки и поиска на полном наборе ещё требует измерения.
